# PCB와 상태머신 요구사항 차이 분석

## 분석 대상

PCB 정보는 제공된 `부품배치.html`의 board SHA-256
`2d06e74f7b4438a6ee7a14d682d6ec5f269cd94d18c1ecd0cc4048d5dde9b4e6`에서
추출했다. 보드는 140 mm x 80 mm이고 ESP32-S3-DevKitC-1-N32R16V,
BNO085, BMP388, Adafruit microSD, E22-900T30D-V2, 2개 히터 채널을 사용한다.

## 충족되는 기능

| 요구 | PCB 구현 | 결과 |
|---|---|---|
| 자세 및 가속도 | BNO085 SPI | 가능 |
| 기압고도 | BMP388 I2C | 가능 |
| 로컬 기록 | Adafruit microSD SPI | 가능 |
| 5 Hz 무선 텔레메트리 | E22 UART | 기본 송신 가능 |
| 배터리 전압 | 100 kOhm / 22 kOhm 분압과 ADC | 보정 후 가능 |
| 1단 및 2단 구분 | J7 개방=1단, 점퍼 장착=2단 | 가능, 인계 BOM으로 극성 확인 |
| 가열 출력 | J8 및 J9 두 채널과 공통 HEAT_ARM | 벤치 차단 상태로 관찰 가능 |

## 비행을 막는 차이

| 설계서 요구 | PCB 상태 | 필요한 조치 |
|---|---|---|
| 물리 아밍 스위치와 LoRa ARM 동시 조건 | 아밍 입력 없음 | 독립 하드웨어 키 또는 스위치 입력 추가 |
| 20 ms 디바운스 분리 확인 | 분리 감지 입력 없음 | 커넥터, 보호회로, 풀업 및 디바운스 입력 추가 |
| 발사 전 파이로 연속성 | 연속성 측정 입력 없음 | 전류 제한 측정회로와 ADC 또는 비교기 추가 |
| 서스테이너 점화+주 사출+백업 사출 | 히터 출력 2개 | 독립 3번째 채널 추가 또는 백업 생략을 공식 결정 |
| 하드웨어 아밍과 소프트웨어 차단 이중화 | HEAT_ARM도 MCU GPIO | MCU 고장과 독립된 전원 차단 추가 |
| 비행 중 리셋 후 고도 20 m 판단 | 기준고도 비휘발 저장 없음 | CRC를 포함한 NVS 또는 FRAM 저장 정책 추가 |

## 센서와 기구 확인 사항

PCB에서 로켓 종축 방향을 알 수 없다. 프로토타입은 임시로 PCB `+X`를 종축으로
사용한다. 실제 장착 방향이 다르면 기울기와 적분속도가 모두 잘못되어 2단 점화
허용 판단에 사용할 수 없다. BNO085의 자기장 보정은 점화 판단에 직접 사용하지
않지만, 회전 벡터 드리프트와 진동 성능은 지그 및 진동 시험으로 확인해야 한다.

BMP388은 부팅 후 10초 평균을 상대고도 0 m로 잡는다. 부팅 후 기체를 움직이면
기준고도가 틀어지므로 교정 완료 부저 또는 LED 절차가 필요하다. CEVA의
[BNO08X 데이터시트](https://www.ceva-ip.com/wp-content/uploads/2019/10/BNO080_085-Datasheet.pdf)는
가속도 범위를 ±8 G로 명시하지만 제공된 시뮬레이션의 예상치는 최대 약 9.4 G다.
따라서 최고 가속 구간에서 포화될 수 있고 적분속도는 실제보다 작게 계산될 수
있다. 별도 고가속도 센서를 추가하거나 비행 프로파일 재생과 원심 또는 진동
시험으로 점화 허용 속도의 신뢰성을 입증하기 전에는 이 값을 점화 판단에
사용하면 안 된다.

## 권장 PCB 수정 우선순위

1. 독립 하드웨어 아밍 차단과 상태 입력을 추가한다.
2. 분리 감지 및 각 채널 연속성 입력을 추가한다.
3. 서스테이너용 세 번째 독립 출력 채널을 추가한다.
4. 모든 외부 입력에 ESD, 과전압, 역전류 보호를 검토한다.
5. MCU 리셋 상태에서 모든 출력이 확실히 OFF인지 전원 상승 및 브라운아웃
   파형으로 검증한다.
6. 시험용 헤더에 아밍, 분리, 연속성, 출력 게이트를 노출해 자동화된 HIL 시험을
   가능하게 한다.
