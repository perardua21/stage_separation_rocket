# PCB 납땜 및 센서 점검 절차

## 안전 준비

- 점화기, 사출 화약, 모터는 모두 분리한다.
- 처음 전원을 넣기 전 3.3 V, 5 V, VBAT과 GND 사이의 단락을 멀티미터로
  확인한다.
- 첫 전원은 전류 제한이 가능한 벤치 전원을 사용한다.
- 진단 펌웨어는 `HEAT_ARM`, `HEAT_IN1`, `HEAT_IN2`를 항상 LOW로 유지한다.

## 빌드 및 업로드

```bash
pio run -e pcb_bringup
pio run -e pcb_bringup -t upload
pio device monitor -b 115200
```

생성된 바이너리는 `.pio/build/pcb_bringup/firmware.bin`이다.

## 자동 검사 항목

| 항목 | 검사 방법 | PASS 의미 |
|---|---|---|
| 5 V 감지 | `MAIN_5V_PRESENT` 입력 | Q6 오픈드레인 감지 입력 LOW |
| 배터리 ADC | HAL을 통한 전압 읽기 | 유한하고 포화되지 않은 값 |
| BNO085 | 격리 태스크에서 SPI 초기화 및 데이터 수신 | 가속도와 자세 데이터 수신 |
| BMP388 | I2C 0x77, chip ID 0x50 초기화 후 데이터 | 압력·온도가 물리 범위 안에 있음 |
| microSD | 파일 생성, 기록, 재읽기 | 기록한 문자열과 읽은 문자열 일치 |
| E22 | M0/M1 normal mode, AUX, UART 송신 | AUX HIGH; 실제 RF는 상대 무전기로 확인 |

LED와 부저는 차례로 구동되므로 사람이 직접 확인한다. J7 단계 식별 결과도
시리얼에 출력되므로 점퍼를 열고 닫았을 때 결과가 바뀌는지 각각 확인한다.

## 결과 해석

- `PASS`: MCU에서 해당 부품과 기본 통신이 확인됨
- `WARN`: 외부 계측기, 눈 또는 상대 장치로 추가 확인 필요
- `FAIL`: 전원, 방향, 납땜 브리지, 핀 연결 및 부품 실장을 확인해야 함
- `SKIP`: 안전상 자동 시험하지 않은 항목

이 검사에 통과해도 모든 납땜 접합의 기계적 강도나 히터 전력 경로까지 보증하지
않는다. 히터 경로는 점화기 대신 더미 부하를 연결한 별도 승인 절차로 시험한다.
