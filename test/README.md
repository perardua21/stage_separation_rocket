# 테스트

## 호스트 리플레이 (`pio test -e native`)

FSM과 판정기는 하드웨어 없이 돌 수 있게 만든다. 시뮬이나 실비행 로그에서
뽑은 `nav_state_t` 시퀀스를 넣고 상태 전이 시각을 확인한다.

| 시나리오 | 입력 | 확인할 것 |
|---|---|---|
| 부스터 정상 | 시뮬 프로파일 | SEPARATING 진입, 분리 게이트 3개 통과 시각, APOGEE 시각 |
| **분리 고도 미달** | 조기 연소종료로 최고 80 m | 분리 열선이 한 번도 안 켜짐, RECOVERY 진입 |
| 부스터 분리 실패 | 분리 확인 신호 없음 | 재시도 1회 후 `t0`+2.5 s에 RECOVERY |
| 서스테이너 정상 | 시뮬 프로파일 | 점화 1회, 게이트 5개 값 로그 확인 |
| 기울기 초과 | 분리 후 25도 | 즉시 RECOVERY(TILT), 점화 없음 |
| 속도·고도 부족 | 적분 속도 25 m/s | 창 종료 시 RECOVERY, 점화 없음 |
| 점화 실패 | 가속도 안 오름 | RECOVERY(NO_IGN), 재점화 없음 |
| 기압 고장 | 고도값 고정 | 강제 타이머로 사출 |
| 비행 중 센서 고장 | 발사 후 IMU 고장 | SAFE가 아니라 RECOVERY |
| 열선 시퀀스 | 정점 도달 | ARM -> CH_A -> 간격 -> CH_B -> ARM OFF 순서와 시각 |
| 동시 구동 금지 | CH1 켜진 상태에서 CH2 요청 | 거부되는지 |

## 벤치 (`pio run -e bench`)

`NURA_DISABLE_HEATER_OUTPUT`이 켜져서 열선 핀이 컴파일 단계에서 빠진다.
LED와 로그로만 시퀀스를 확인한다. **비행에 쓰지 말 것.**

## 지상시험으로 확정할 값

| 값 | 상수 | 방법 |
|---|---|---|
| 열선 펄스 길이 | `CFG_HEAT_PULSE_MS` | 실제 열선·배터리로 절단 시험. 전압 떨어진 상태에서도 |
| 열선 전류 | - | 15 A 퓨즈 여유 확인, 동시 구동 금지 검증 |
| 분리 확인 지연 | `CFG_SEP_CONFIRM_TO_MS` | 분리 기구 지상시험 |
| 점화기 지연 | `CFG_S_IGN_CONFIRM_TO_MS` | 점화 시험. 1.0 s가 충분한지 |
| 기압 노이즈 | `CFG_APOGEE_DROP_M` | 정지 상태에서 고도 흔들림 측정 |
| BNO085 포화 | - | 진동대 또는 낙하로 ±8 g 포화 여부 확인 |
